One Base Unit.
Twenty Applications.

Ward Effect® devices are made available to licensees and territorial partners through wholesale arrangements. Each device is built on a single universal base unit — the Ward Effect® Node — with interchangeable application heads and LEF libraries.

The Model

How It Works

Core hardware

The Base Unit

The Ward Effect® Node — LM386 amplifier and ESP32 microcontroller. This is the universal instrument. It does not change between applications. Licensees sell the base unit as the entry product, then grow revenue through additional heads and libraries.

Application system

Head + Library

Each application requires a matching transducer head — the mic/speaker assembly shaped and housed for the specific task — and a spectral fingerprint LEF library loaded into the unit. Head and library are sold as upgrades, generating ongoing revenue from a single installed base.

For territorial licensees: Purchase the base unit and application heads at wholesale price. Set your own retail price. As your customers expand into new applications, they purchase additional heads and libraries — recurring revenue from a single installed base. Exclusive territorial rights are available.
