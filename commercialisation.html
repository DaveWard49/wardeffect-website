The Platform

One Base Unit — Interchangeable Modules

Ward Effect Technology is built around a single base unit — the same concept as a digital multimeter that measures voltage, current, resistance, and continuity with the same instrument, or a professional power tool platform where one battery and motor unit accepts twenty different tool heads.

The Ward Effect base unit contains the microcontroller, amplifier, LEF library system, power management, and communications. What changes between applications is the transducer module — the speaker and microphone configuration adapted for the specific measurement task. A contact transducer on a pipe detects leaks. A submerged module in a bucket purifies water. A surface-mounted array on a tile detects delamination. A clamp-on module on a tank monitors chlorine. The base unit is identical in every case.

The library does the rest. Each application loads its own LEF library — the pre-built set of oscillation fingerprints for that specific measurement task. Swapping the transducer module and loading the matching library reconfigures the instrument completely. No new electronics. No new firmware. No new training.

⚙ The Base Unit

ESP32 microcontroller, LM386 amplifier, LEF library system, LoRa mesh networking, LiPo power management, SD logging. One unit. All applications. Target cost: 5 at scale.

🔌 Interchangeable Modules

Contact transducers, clamp-on sensors, submerged probes, surface-mounted arrays, flexible PVDF sheets. Each module is a speaker/microphone pair configured for its application — like a power tool adaptor.

📚 The Library

Each application ships with its own LEF library — pre-built oscillation fingerprints for that measurement task. Swap the module, load the library, the instrument is reconfigured. No new hardware required.

Commercial Model

Buy the Base — Add What You Need

The Ward Effect commercial model is straightforward. The customer buys one base unit. Every additional application is unlocked by purchasing the matching transducer module and library. The base unit never changes. Capability grows with each module added.

Each application module is available in wired or wireless configuration. The choice is entirely application-driven — wired for fixed, accessible targets where a cable is no inconvenience; wireless for remote, rotating, submerged, or hazardous environments where cable access is impractical. The base unit accepts both. The Ward Effect locks onto a stable oscillation in either configuration — the fingerprint library is simply built for the chosen setup.

Best for: Ship hulls, buried pipes, rotating machinery, offshore structures, hazardous or inaccessible locations.

Step 3
