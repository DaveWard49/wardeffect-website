Ward Effect devices are sold wholesale to affiliates. Each device is built on a single universal base unit — the Ward Effect Node — with interchangeable application heads and libraries.

The Model

How It Works

Core hardware

The Base Unit

The Ward Effect Node — LM386 amplifier and ESP32 microcontroller. This is the universal instrument. It does not change between applications. Affiliates sell the base unit as the entry product.

Application system

Head + Library

Each application requires a matching transducer head — the mic/speaker assembly shaped and housed for the specific task — and a spectral fingerprint library loaded into the unit. Head and library are sold as upgrades.

For affiliates: Buy the base unit and application heads at wholesale price. Sell at retail. As your customers expand into new applications, they purchase additional heads and libraries — ongoing revenue from a single installed base.
